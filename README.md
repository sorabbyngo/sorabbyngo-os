# Sorabbyngo OS — OS ONE

**The Rhythm of Digital Life.**

Sorabbyngo OS is an open-source operating system project exploring a
new approach to personal computing through spatial interaction,
a carefully engineered Linux foundation, and an architecture
designed for future AI-native computing.

## OS ONE

OS ONE is the first product milestone of Sorabbyngo OS.

The initial direction is a laptop-first spatial desktop built for
conventional displays. The first release focuses on the desktop
experience and operating-system foundation, without requiring AI
services or specialized VR hardware.

### Our direction

- A spatial desktop experience for everyday computing.
- A Fedora-derived, image-based operating-system foundation.
- Wayland-based desktop technology.
- A modular architecture that can evolve over time.
- An open-source development process.

### Architecture

Sorabbyngo OS is developed as a collection of cooperating projects.

The engineering organization contains the development repositories,
including:

- **Vanta** — spatial desktop and compositor development.
- **Fedora Base** — operating-system foundation and image definitions.
- **HAL** — hardware abstraction research and development.
- **ObjectSpace** — spatial object model and runtime research.
- **AION** — future AI runtime and control plane.
- **CHAMEHA** — future AI personality and interaction engine.

Not every architectural component is production-ready. Some remain
experimental, under development, or at the design stage.

## Project status

OS ONE is under active development.

It is not yet a stable, production-ready operating system.
Release announcements will clearly identify the maturity and
limitations of each published build.

## Project philosophy

Models come and go. The path from intent to effect stays yours.

We believe the operating system should remain understandable,
controllable, and useful as computing evolves.
